# 设置

点击主界面右上角的**设置图标**，即可进入设置页面。这里的所有设置都会在你更改后**自动保存**，并在下次启动应用时生效。

![设置页面](https://github.com/user-attachments/assets/57223010-f168-4545-911c-223689433434)


## 可用设置项

- **语言 (Language)**
  - 通过下拉菜单选择应用的界面语言。目前支持"English"和"中文"。
  - 更改后，整个应用的 UI 会立即更新。

- **主题 (Theme)**
  - 亮色 / 暗色 / 跟随系统三种明暗模式。
  - 外加 **6 种主题色**可选：Teal（默认）、Blue、Indigo、Violet、Rose、Green。选中的颜色不只是按钮高亮色，还会派生出整个界面的背景、面板、分隔线等中性色调——换一个主题色相当于换一次整体皮肤。

- **界面字体 (UI Font)**
  - 系统默认 / HarmonyOS Sans / MiSans 三选一。
  - 选择非系统字体后会按需自动下载对应的字体文件。

- **描述文件扩展名 (Caption Extension)**
  - 定义了工具在加载和保存"当前激活"描述文件时使用的文件扩展名。
  - 默认值为 `.txt`。
  - 例如，如果你将其修改为 `.caption`，那么在选择 `image1.png` 时，工具会去寻找并加载 `image1.caption`。

- **Caption 类型管理**
  - 一张图可以同时维护多份不同扩展名的描述文件（比如打标签用的 `.txt` 和自然语言描述用的 `.ntxt`）。
  - 在这里可以新增、启用/禁用某个 caption 类型，为它命名并指定扩展名。
  - 可以把某个类型标记为**散文（句子模式）**：标签化视图会按逗号/句号把它的文本分成一句句短语展示，而不是当作逗号分隔的 danbooru 标签处理。
  - 启用了不止一个类型之后，AI 助手会多出几个用来检查覆盖情况、读写指定类型文件的专用工具。

- **标签词典 (Tag Dictionary)**
  - 内置约 1.1 万条 Danbooru 标签，随包发布，完全离线可用，与 WD tagger 输出的词表保持一致。
  - 也可以一键下载按热度排序的前 10 万条完整词典，额外带别名、画师与作品分类。
  - **编辑词典**：可以编辑任意标签的译文与注释、添加 Danbooru 没有的标签（自带分类，会进入补全并排在最前）、导入导出译文表，以及一键清除 AI 生成的译文（手写的会保留）。
  - **从 Danbooru 获取**：粘贴 Danbooru 地址（wiki 页 / 投稿搜索 / 标签列表）或直接填标签名，读取其公开 API 拿到分类、收录量、`other_names`（多为日文的其他语言名称）和 wiki 摘要。这些都只是候选，点一下才会真正填进译文或注释。

- **LLM 后端配置 (LLM Backends)**
  - 供 **AI 助手**使用的对话模型配置。分两级：先添加一个**服务商**（地址 + API 密钥），再在其下添加具体的**模型**（模型 ID、显示名、上下文窗口挡位从 8K 到 1M 可选、最大输出 token、温度、是否支持视觉、可选每百万 token 计价）。
  - 内置几个常用服务商的快速预设：OpenAI、Gemini（OpenAI 兼容接口）、Ollama（本地，默认 `http://127.0.0.1:11434/v1`）、Anthropic。
  - 也可以直接在 AI 助手面板标题下方的按钮里临时切换已配置好的模型；切换会开启一个全新会话。

- **AI 助手设置**
  - **会话用量上限**：一次会话最多花多少 token，可选 500K / 1M / 2M / 5M，或 0 表示不限，默认 100 万。每轮对话都会带上完整历史，批量操作耗 token 很快；用尽后开一个新会话即可，这项设置只影响下一次新建的会话。
  - **写操作是否需要确认**：默认每条改写类操作都要你逐条确认，也可以在设置里改成全部自动放行。
  - **预置提示词管理**：增删改你保存的常用提示词，供面板的书签图标菜单一键插入。

- **数据导入导出 (Export / Import Data)**
  - 在侧栏的**数据**分组里，把你手工攒出来的配置打包成一个 JSON 文件，换机器或重装后导入即可恢复。
  - 可分别勾选三部分：**AI 后端配置**（可选是否包含 API 密钥——密钥会以明文写入文件，请妥善保管）、**自定义标签库**（分组及其颜色、分组内外的标签、你自己加进词典的标签、以及**所有语言**的译文）、**预置提示词**。
  - **不包含**内置词表和下载的 Danbooru 全量词典：这两样随时可以重新获取，没必要塞进备份。
  - 导入时先选文件，再选要恢复哪几部分，以及遇到已存在的内容时**保留本机已有**还是**以文件为准**。两种方式都只会新增或更新，**绝不删除**本机已有的东西——清空请用各自面板里的清空按钮。

- **重置设置 (Reset Settings)**
  - 这是一个危险操作，因此按钮被设计为红色。
  - 点击后会弹出一个确认对话框，以防止误触。
  - 确认后，**所有**设置（包括语言、主题、扩展名、公共标签库、LLM 后端配置、上次打开的目录等）都将被清除，并恢复到初始的默认状态。
