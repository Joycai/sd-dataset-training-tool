# Code layout

Layer-first layout under `lib/`. Each layer may import the layers listed
below it, never the ones above.

| Directory | Holds | May import |
| --- | --- | --- |
| `views/` | Screens, panels and dialogs: app-specific UI that knows which feature it belongs to | everything below |
| `widgets/` | Reusable UI building blocks. No imports from `views/` | `state/`, `services/`, `models/`, `theme/`, `utils/`, `l10n/` |
| `state/` | `ChangeNotifier`s exposed through Provider (`AppState`, `DatasetState`, …) and controllers that drive them (`TagOps`, `DataTransfer`) | `agent/`, `services/`, `models/`, `theme/`, `utils/`, `app_info.dart` |
| `agent/` | The LLM agent runtime (`AgentSession`) and its tools. The tools act on app state, so this folder and `state/` import each other by design | `state/`, `services/`, `models/`, `utils/` |
| `services/` | I/O and external systems: settings storage, HTTP APIs, LLM clients (`services/llm/`), fonts, dictionaries. No imports from `state/` | `models/`, `theme/`, `utils/`, `app_info.dart` |
| `models/` | Plain data types and their pure logic. No Flutter widgets, no state | other `models/` |
| `theme/`, `utils/` | Design tokens and theme; small pure helpers | `models/` only |
| `l10n/` | `.arb` sources; `app_localizations*.dart` is generated by `flutter gen-l10n`, never edited | none |

Inside `views/`:

- `workbench/`: the main window shell (`WorkbenchView`, its top bar, icon rail, status bar).
- `panels/`: the docked panels and the pieces they share (for example `tag_context_menu.dart`).
- `dialogs/`: every modal opened via `show…Dialog`.

## Conventions

- Files are `snake_case.dart`, one public widget or concept per file.
  Private helper widgets stay in the file that uses them.
- Inside `lib/`, import with relative paths (`prefer_relative_imports`).
  Tests import with `package:dataset_training_tool/...`.
- `test/` mirrors `lib/`: a test for `lib/state/tag_ops.dart` lives at
  `test/state/tag_ops_test.dart`. `test/widget_test.dart` is the app smoke test.
- Before pushing, run the same checks CI runs:

  ```bash
  dart format --output=none --set-exit-if-changed lib test tool
  flutter analyze
  flutter test
  ```

Lint rules live in `analysis_options.yaml`, on top of `flutter_lints`.
